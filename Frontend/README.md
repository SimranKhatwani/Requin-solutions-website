# Requin Solutions - Frontend

Modern React 19 + Vite + Tailwind CSS frontend application for Requin Solutions website and Admin CMS panel.

## Features
- **Public Website**: Landing page, Services, Case Studies & Projects, Blogs, Company Story & Timeline, Contact, Interactive Quote Quiz, Live AI Chatbot.
- **Admin CMS Panel** (`/admin`): Complete CMS management for Blogs, Projects, Milestones/Stories, Media Gallery, and Admin Authentication.
- **Modern UI/UX**: Tailwind CSS, Lucide icons, Motion animations.

## Getting Started

### Prerequisites
- Node.js 18+ or Bun

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Runs the Vite development server on `http://localhost:5173`. Proxies `/api` requests to backend on port 5000.

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
